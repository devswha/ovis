### Added
- Move everything to herdr-core in one click (Settings > About, on a PC running herdr): every
  workspace, tab, split and pane name comes along, each idle agent reopens on its own conversation
  (or starts new in the same folder when its conversation cannot be told), and shells start in the
  same folder. Nothing moves while an agent works or a shell runs a command: the move waits for
  them. If any step fails, everything is put back in herdr; herdr itself is never closed.
