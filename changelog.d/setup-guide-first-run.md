### Added
- A setup guide on a fresh install: Ovis asks whether this is your first time, then checks which
  coding agents this PC has. With one there, a single screen offers Start, which opens your first
  project with it (Claude Code, else Codex, else the first found) and shows plan usage for accounts
  already signed in. With none, one tap installs Claude Code (or Codex, or another agent) with its
  official installer and opens its sign-in, then Start. Connecting a phone and alerts are links to
  Settings. It opens by itself only once, when herdr has no workspaces and Ovis has no saved
  settings or paired devices; "I've used Ovis before" goes straight to the app.
