### Added
- Files can show a **Documents** tab (Settings > Chat > Documents in Files, off by default): the
  Markdown files under the pane's folder, newest first, with a filter and a Refresh button. A row
  opens the file in the viewer, which renders it. It lists what @-mentions search (git's files
  that are not ignored, or a bounded walk outside a repository), on another PC too, and a
  watching device cannot list them.
