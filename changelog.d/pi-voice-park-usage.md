### Added
- A live voice call can be parked: while Pi runs a long task it lets go of the voice session, so the
  call stops using voice time. The orb sleeps with a note that the voice returns with the result,
  End stays in reach, and a tap on the orb asks for the voice back now. This needs a Pi with the
  matching pi-better-openai.
- The call's controls show the voice time it has used, as minutes and seconds.
