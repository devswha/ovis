### Added
- Settings → Devices and PCs → Add a connection → Ovis relay now has "Add with a QR code" whether
  or not the page is signed in: press Show the QR code and scan it with a device that is signed in
  to your Ovis account, and a PC that is in no account joins that account with no number to type
  and no approval on the PC (on a PC already in an account the scan only pairs that device). The
  code is made only on that press, is shown as a QR code alone with no code to type, and is ended
  when the dialog closes, another tab opens, the page is reloaded or closed, the page was hidden
  for a minute, or after 30 minutes. The dialog then says which account the PC joined, whether it
  is the one this browser is signed in to, and which device of that account added it, with "Not
  me: revoke every device"; any other device the code let in is named and asked about, with "Not
  me: remove it" first. A notice that was not answered comes back the next time Devices and PCs
  is opened.
