### Added
- An omp pane's todo list now shows as its plan, and the subagents it runs as its background
  tasks, in the message box's plan and background-tasks chip, as for Claude Code, Codex, OmO and
  OpenCode panes.
- Settings → Chat → Composer → **Plan card above the message box** (off by default, per device)
  pins the plan and the running background tasks in a card above the message box for every agent
  that reports them. The card's header folds it to one line, and a running Claude Code or OpenCode
  subagent opens its work from it as it does from the chip.
